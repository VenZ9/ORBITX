# OrbitX Launcher (Android)

Minecraft: Java Edition 的 Android 啟動器，由 **Zalith Launcher 1.4.1.4**
（GPL-3.0）重新命名並改為紅色主題，即 **OrbitX**。Zalith Launcher 又基於
**PojavLauncher**（LGPL-3.0）的執行環境。
