# OrbitX Launcher (Android)

Minecraft: Java Edition 的安卓启动器，由 **Zalith Launcher 1.4.1.4**（GPL-3.0）
重新命名并改为红色主题，即 **OrbitX**。Zalith Launcher 又基于 **PojavLauncher**
（LGPL-3.0）的运行时。
